# Rebrand or keep

Read this file when the user asks whether to *change* a current name. Weigh these tests in order. The numbers are rules of thumb, not hard limits.

1. **Must change.** The name is illegal, a prior mark blocks it, or it is offensive or hard to say in a new market.
2. **Lean to change.** The name now describes only a small part of the business, about 30% or less (Restoration Hardware became RH). Or the name carries a lasting bad link (ValuJet became AirTran after the 1996 crash).
3. **Lean to keep.** The name has years of built-up value (5 or more is a common bar). Or the pain comes from the company's reputation, not the name, so fix the reputation. Or the new name stands out no more than the current one (the Tronc trap).
